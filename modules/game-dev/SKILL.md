# 游戏设计通用守则

## 一、发动机优先（最重要的一条）
1. **不凭空发明核心玩法**：新游戏先选一个被商业验证过的"玩法发动机"（某成熟品类的核心循环）做骨架，用自己的题材/世界观/内容重构；原创留给内容层，不留给发动机层。
2. **主次组装不做平均拼盘**：多个参考作品要定配比（如 80/15/5），主模版承重，其余只供局部模块与质感；平均撒进去=模块堆砌。
3. **先例五问**（新系统/新阶段一律过）：给玩家什么体验→哪些成熟产品成功提供过→靠什么具体机制→能否迁移进现有循环→无可靠先例时值得自创风险吗。找不到先例的中间层/新阶段，宁可让已验证系统渐进交接，不造第三套发动机。
4. **玩法先例≠题材先例**：借的是决策结构/因果链/回收方式，不是皮和名词。

## 二、设计纪律
5. **设计职责两问**（一切玩家可见元素）：它给玩家什么决策/情绪？拿掉损失什么？答不出=不做。
6. **设计先于文案**：交互单位先过设计层（决定什么/选项为何互斥/决定前已知什么/后果接到哪/复用类型），再写字。好看的短文案≠能玩的游戏内容。
7. **选项即承诺**：真互斥、同决策层级、选前信息足以形成意图、结果不换题；每项选择须有即时可感的世界回应。
8. **新概念引入**：玩家决定前不许有未解释生词；用教学/演出/重复物件/前后文引入；禁止为题材感发明只服务单条内容的新物件新规则（作者掌握没交给玩家的规则=失败）。
9. **信息只保留当下决策所需**：单屏信息量红线意识；世界观设定可以比玩家所见更完整，但正文必须迅速讲清"此刻发生什么、为什么要决定"。

## 三、验收与真相
10. **占位不冒充设计,三层分账**：代码里已有≠已裁决≠玩家拿到成立的体验；占位公式/占位内容/工作骨架都会伪装成"已定"——查不到设计决定出处的一律当占位;完成度账三格分列(仓里有/设计审过/玩家拿到),"已实装"只证第一格,资产存在不是恢复上线的理由。
11. **首件门**：每类资产/内容首件先过质量门再量产；参照系=同品类市售成品并排对比（"比上一版好"≠"达到商品级"），验收人回答"消费者会把它当什么档次"。
12. **尝味给玩家可见内容**：给人类拍板者品鉴的必须是玩家实际看到的形态（正文/选项/画面），设计稿只作附件。
13. **证据来自真实状态**：验收截图/数据必须出自真实运行路径；测试夹具显式标注，不冒充用户可达状态。
14. **自检全过=警报**：批量自检零 FAIL 说明筛选器失去区分度，先怀疑尺子再庆祝。
15. **数据驱动**：数值/文案/开关/权重进配置表，拍板者的小反馈应分钟级可改。

## 四、防模板与长线
16. **防结构千篇一律**：量产内容监控结构分布（选项数/句式/手法/意象），同一模式超阈值即报警；结构变化是产法的一部分。
17. **多周目/重复内容**：重复出现的关键内容须有变体或回调方案；"世界告诉我一个只属于我的答案"类揭示不可原样重播。
18. **完整度即体验**：品类标配的 game chrome（设置/存档/回看/跳过/成就）缺了就是半成品；未落地项进底账不许静默消失。

## 五、成熟参考的设计层逆向(见核原理 4/6/7;此处给游戏专用细则)
19. **先认槽位再填**:把参考的具体实现扒到"这个东西为什么存在、承担什么设计职责"再谈继承/替换/融合/原创;槽位可能本不该存在(历史遗留/拍脑袋/没解决好),不为既存设计发明目的。
20. **一生/一局的机器要拆到机器层**:什么是稳定骨架(时间线/固定位)、什么随状态/选择/关系/随机变(门筛/变体/行动/随机/周目)、内容与玩法怎样互作用——只知道"有阶段、有事件池、没固定剧情"不算拆透;拆完写成一屏人话能给玩过原作的人讲,那是最便宜的验收。
21. **横穿阶段的持续玩法不得因不属于"年龄节点"而从骨架里消失**:完整骨架至少两视图——人生/局怎样按阶段推进;战斗、构筑、关系、经济、内容推进等 engine 怎样跨阶段运转、在哪小规模兑现、在哪被大检验。
22. **供体资格与 MOD 证据**:一款游戏有某功能≠有资格当这一槽位的供体(要证明它在这一科做得好,或明示为反例);成熟 MOD/创意工坊/社区补丁=在同一宿主、相近接口、同一玩家群里实际跑过的替代零件,证据链五环(原作痛点→针对性修改→可运行→长期大量采用→反馈指向痛点改善);热门≠正确,区分降难度/便利型与真解题型。
23. **"无直接答案"不等于无信息**:结论为"无成熟供体"时说清为什么没有、各参考给了哪些局部启发(谁站在哪个极端)、真正必须原创的是哪部分。
24. **发现弱点≠必修,别人没修≠不能修**:把改善价值与真实成本(体量、最小依赖闭包、QA)一起拿给拍板者;"同体量产品都停在这"要拆成"设计机会未被解决"与"成本过高被接受"两个竞争解释再判。
