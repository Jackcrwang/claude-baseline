# claude-baseline：跨项目协作基线

个人协作守则库：Claude 工作习惯、Claude×Codex 协作模式、通用工作流、游戏设计通用守则。**零全局钩子**——任何窗口只有在你亲口说激活句时才会接触本仓库；不装载的项目（尤其隔离项目）物理上不存在被加载的路径。

## 激活句（复制粘贴，替换尖括号）

> 读取 `<本仓库路径>/BOOTSTRAP.md`，按其流程为本项目装载守则。项目简介：<一两句：做什么、预期规模、是否用 Codex>

本机路径示例：`E:\workflows\claude-baseline\BOOTSTRAP.md`。新电脑先 `git clone <仓库URL> `到任意位置，激活句里的路径换成 clone 位置即可。

## 结构

```
core/CLAUDE.md           薄核：沟通协议/诚实底线/方法论/任务分档（装载后每会话生效）
modules/workflow/        中重档工作流：工单制/交接/多代理/验收分级/证据纪律
modules/game-dev/        游戏设计通用守则（发动机优先/先例五问/首件门/防模板）
modules/codex-collab/    Codex 协作模式（默认启用；派单纪律/跨家族异源审查）
templates/               方向日志/工单/回执/恢复块 四模板（重档项目用）
BOOTSTRAP.md             装载协议（判定表/护栏/临时vs安装两模式）
```

## 三条不变式

1. **隔离＞一切**：永不写 `~/.claude/`；隔离项目（当前为 `E:\A`）拒绝安装模式；唯一入口=你手动粘贴的激活句。
2. **自动判断，不自动生效**：装载器按项目简介拟清单，复述后等你确认。
3. **更新自由**：任何窗口受你指示可提交改进（项目结项沉淀等）；条款修改保住原效力等级。
